# 🚀 Machine Learning & Data Science Projects

Welcome to my repository of **Machine Learning** and **Data Science** projects. Here, I showcase various projects where I applied data analysis, predictive modeling, and advanced machine learning algorithms to real-world datasets. From **autism prediction** to **diabetes diagnosis** and **sales data analysis**, each project demonstrates my proficiency in Python and data-driven solutions.

---

## 📋 Projects Overview

### 1. **Autism Prediction**  
**Technologies:** Python, Pandas, Scikit-learn, Random Forest, Decision Tree, XGBoost  
**Description:**
- Developed a model to predict autism with an accuracy of **82%**.
- Used **Random Forest**, **Decision Tree**, and **XGBoost** algorithms for classification.
- Processed **500+ records** with feature engineering to improve performance.
- Applied **Grid Search** for hyperparameter tuning to optimize the model.

---

### 2. **Sugarcane Production Data Analysis & Visualization**  
**Technologies:** Python, Pandas, Matplotlib, Seaborn  
**Description:**
- Analyzed **10+ years** of sugarcane production data to uncover yield-impacting factors.
- Created **5+ interactive visualizations** to display trends in productivity.
- Used **correlation analysis** and **regression techniques** to derive actionable insights for improving yield.

---

### 3. **Diabetes Prediction**  
**Technologies:** Python, Pandas, Matplotlib, Seaborn  
**Description:**
- Developed a classification model to predict diabetes with an accuracy of **85%**.
- Processed **700+ patient records** and engineered key features such as **BMI** and **blood pressure**.
- Applied **Logistic Regression** and **KNN** models with cross-validation to evaluate the model.

---

### 4. **Black Friday Sales Data Analysis**  
**Technologies:** Python, Pandas, Matplotlib, Seaborn  
**Description:**
- Analyzed **500,000+ transactions** to uncover purchasing patterns during Black Friday sales.
- Created **7+ data visualizations** to aid marketing and sales strategies.
- Performed **cluster analysis** and **trend forecasting** to assess sales event impact.
